# 💇‍♀️ Helpit Beauty Manager

## Sistema Completo de Gestão para Salões de Beleza

O **Helpit Beauty Manager** é uma plataforma SaaS desenvolvida para salões de beleza, barbearias, clínicas de estética e profissionais da área da beleza que desejam centralizar toda a operação do negócio em um único sistema.

Com uma interface moderna, intuitiva e acessível em qualquer dispositivo, o sistema oferece controle total sobre agendamentos, clientes, profissionais, financeiro, estoque, comandas e muito mais.
